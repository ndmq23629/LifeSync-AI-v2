# Monetization thực chiến cho LifeSync AI

## Free
Mục tiêu: hút user, tạo habit loop
- Pomodoro
- task / habit
- ghi thu chi thủ công
- BMI, mood check-in
- export JSON

## Pro (99k/tháng gợi ý)
Mục tiêu: tạo MRR
- AI insight tài chính
- sync đa thiết bị
- weekly report
- push nhắc đúng ngữ cảnh
- lưu snapshot cloud

## AI Credit
Mục tiêu: không lỗ API
- phân tích dài
- plan 30 ngày
- báo cáo tổng hợp
- coach theo mục tiêu
- xuất checklist / action plan nâng cao

## KPI cần theo dõi
- DAU/WAU
- D7 retention
- số phiên pomodoro / tuần
- số ngày ghi chi tiêu liên tiếp
- conversion Free -> Pro
- cost / request AI
- credits used / user

## Cảnh báo
- Không mở AI vô hạn cho free tier
- Không để backend gọi model đắt cho tác vụ đơn giản
- Không để push thành spam
